# Bot Jubesvaldo  

O bot jubesvaldo foi criado com o intuito de poder exercer multiplas funções no **Servidor do Becario**, como moderação, funções conversa, funções para jogos e funções para estudo.  

## Testando o projeto
### Bibliotecas necessárias

Para testar este projeto será necessário instalar as bibliotecas do discord, do postgreSQL e do python-dotenv e para isso será necessário rodar os comandos descritos abaixo em seu terminal:  

Para instalar a biblioteca do discord rode `pip install discord.py`  
Para instalar a biblioteca do postgreSQL rode `pip install psycopg2`  
Para instalar a biblioteca do python-dotenv rode `pip install python-dotenv`
