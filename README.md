# Bot Jubesvaldo  

O bot jubesvaldo foi criado com o intuito de poder exercer multiplas funções no **Servidor do Becario**, como moderação, funções conversa, funções para jogos e funções para estudo.  

Para testar este projeto será necessário instalar as bibliotecas do discord, do postgreSQL e do python-dotenv e para será necessário rodar os comandos descritos abaixo:   
Para instalar a biblioteca do discord `pip install discord.py`  
Para instalar a biblioteca do postgreSQL`pip install psycopg2`  
Para instalar a biblioteca do python-dotenv `pip install python-dotenv`
